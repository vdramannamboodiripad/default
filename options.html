Rote

Your answers to the questions every job application asks.

Stored only on this computer, in Chrome's local extension storage. Rote makes no network requests — not now, not ever.

The repetitive ones

Written the way you'd type it, e.g. "30 days" or "2 months".

These two are the ones Rote is most careful about. If a form's wording is at all ambiguous — one box asking for both, or a vague "Salary" — Rote leaves it empty rather than risk putting the wrong number in.

A plain number like "6" usually works in the most places, since some forms only accept digits.

Written out, for forms that give you a text box — e.g. "Indian citizen, no sponsorship required".

The same question is often a Yes/No dropdown — "Are you legally authorized to work in X?" — where a whole sentence isn't one of the options. Put just Yes (or No) here. Leave it empty and Rote will skip those dropdowns instead of guessing.

For dropdown questions, this only fills if one of the options reads exactly like what you type here. "Yes" matches the most dropdowns.

Backup

Export writes a JSON file straight to your downloads folder. It contains your address, phone number and salary figures in plain text, so keep it somewhere you'd keep a bank statement — and don't put it in a git repo.

Erase

Deletes every answer from this computer. Export first if you might want them back — there is no undo here.
