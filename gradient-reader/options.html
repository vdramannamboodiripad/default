Against the wall of text

Line length and leading decide how hard the return sweep is in the first place. Left at zero, each of these leaves the site's own value alone.

Behaviour

The gradient takes a link's colour away, and colour is how a link announces itself. Leave this on unless the sites you read underline theirs already.

Calibrate here

Palettes

Colour is the only thing this extension does, so a palette that collapses into one hue for some readers is not a palette, it is a bug. Red against green is the pair that deuteranopia and protanopia flatten, and roughly 8% of men have one of the two. None of these palettes asks you to tell a red from a green.

Sites

A domain set to always on holds a permission for that one domain and nothing else, so the gradient is simply there next time. Everywhere else, the extension can only act on the page in front of you at the moment you press the button.

Mail, documents, boards and chat apps are on a never-fire list and will not start by themselves whatever this list says. The button still works if you deliberately ask for it.

What this extension can reach

Read from the installed manifest, not written by hand. There is no network permission in the list below, which is why the extension cannot send the text of your pages anywhere: not that it chooses not to, that it has no way to.
